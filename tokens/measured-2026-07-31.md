# Relevé mesuré — Memoria hub, 2026-07-31

Valeurs lues par `getComputedStyle` sur `localhost:8765`, pas transcrites depuis
la feuille de style ni estimées sur capture. Chaque ligne est une valeur que le
navigateur a réellement calculée.

C'est le relevé qui a corrigé la vitrine NDEX : trois versions successives
avaient été écrites en lisant du CSS, et toutes les trois posaient des **pilules
en relief** là où Memoria **creuse des logements**.

---

## 1. La famille de coques — les rayons se répondent

Trois éléments, une seule pièce moulée. Les rayons ne sont pas décoratifs : ils
disent où l'on se trouve dans le boîtier.

| élément | `border-radius` | lecture |
|---|---|---|
| `#top` (plateau haut) | `16px 16px 22px 22px` | moitié **haute** — le bas est plus charnu |
| `.cart` (panneau) | `16px 16px 18px 18px` | module au milieu, presque symétrique |
| barre d'état | `18px 18px 12px 12px` | moitié **basse** — le haut est plus charnu |

Les trois partagent :

```css
border: 2px solid #0d0c12;                          /* la JOINTURE, pas un trait */
background: linear-gradient(180deg, #1a1920, #141318);
```

Le panneau seul monte d'un niveau de surface — il est *posé sur* la coque, pas
taillé dedans :

```css
.cart { background: linear-gradient(180deg, #34323e, #2d2b35); }
```

**La bordure de 2px en `#0d0c12` n'est pas une bordure.** Elle est plus sombre
que le fond de page : elle lit comme le jeu entre deux pièces de plastique
moulées, pas comme un contour dessiné.

## 2. Creusé contre saillant — l'inversion qui décide de tout

C'est le seul point qui compte vraiment. Un module en relief avec une bordure
claire fait une page web ; un logement creusé fait un appareil.

**Saillant** (le plateau, le panneau) :

```css
box-shadow:
  inset 0 1px 0 rgba(255,255,255,.07),     /* la lumière prise sur l'arête haute */
  0 10px 26px rgba(60,52,88,.20);          /* l'ombre portée, TEINTÉE violet */
```

**Creusé** (tout ce qui vit *dans* le plateau) :

```css
background: rgba(0,0,0,.24);               /* pas une couleur : un trou */
box-shadow:
  inset 0 2px 5px rgba(0,0,0,.45),         /* l'ombre que projette le bord du trou */
  0 1px 0 rgba(255,255,255,.07);           /* la lèvre BASSE du trou qui accroche */
```

Les boutons descendent d'un cran : `rgba(0,0,0,.28)`, `inset 0 1.5px 4px
rgba(0,0,0,.5)`, `0 1px 0 rgba(255,255,255,.06)`.

L'ombre portée du plateau est **violette** (`rgba(60,52,88,.20)`), jamais noire.
Une ombre noire sur un fond violet-charbon fait une tache ; une ombre teintée de
la famille fait de la profondeur.

## 3. L'enluminure — la triple bague

Réservée à **la plaque d'identité**, et à elle seule. Trois `box-shadow` de
spread pur, sombre / clair / sombre :

```css
box-shadow:
  inset 0 2px 5px rgba(0,0,0,.45),
  0 0 0 1.5px rgba(10,8,18,.70),
  0 0 0 3.5px rgba(242,239,248,.22),       /* la bague CLAIRE, 2px */
  0 0 0 5.5px rgba(10,8,18,.50);
```

Un chrome autour d'un écran de Game Boy, la plaque vissée au dos d'une manette.
Le fait qu'elle ne serve qu'une fois est ce qui la rend lisible : une bague
partout n'est plus une distinction.

La plaque mesure **40px** de haut quand ses voisins font 46px — elle est plus
petite *parce que* les bagues occupent la différence.

## 4. Les encoches — deux, de natures différentes

### Nervures de préhension, lèvre basse du plateau

```css
#top::after {
  content: "";
  position: absolute; left: 0; right: 0; top: 58px;   /* sur 66px de haut */
  height: 4px;
  background:
    repeating-linear-gradient(90deg, rgba(255,255,255,.16) 0 2px, transparent 2px 7px),
    repeating-linear-gradient(90deg, rgba(255,255,255,.16) 0 2px, transparent 2px 7px);
  background-size: 30px 4px, 30px 4px;
  background-position: 26px 50%, calc(100% - 26px) 50%;
}
```

Barre de 2px toutes les 7px, sur 30px de course, **aux deux extrémités, à 26px
du bord**. C'est l'épaulement strié d'une cartouche SNES ramené à 4px de haut.
La symétrie est ce qui la fait lire comme un moulage plutôt que comme un motif.

### Grille d'aération, contre le badge hexagonal

```css
.idzone::after {
  width: 7px; height: 30px; top: 14px;
  background: repeating-linear-gradient(
    rgba(0,0,0,.34) 0 2px, rgba(255,255,255,.06) 2px 4px);
}
```

Verticale, période de 4px, alternance creux/lumière. C'est la tranche striée de
la cartouche, cette fois dans son axe d'origine.

## 5. L'or, et où il vit vraiment

L'or n'est **jamais** un dégradé qui s'évanouit. C'est un rail plein de 2px,
posé en `inset`.

```css
/* barre d'état — DEUX rails, haut et bas : la barre est cerclée */
box-shadow:
  inset 0  2px 0 #d4a84c,
  inset 0 -2px 0 #d4a84c,
  inset 0  6px 8px rgba(0,0,0,.35),
  0 4px 12px rgba(0,0,0,.25);

/* barre de titre de panneau — UN rail, en dessous */
box-shadow: inset 0 -2px 0 rgba(212,168,76,.55);
```

## 6. Le rail violet — la seule chose qui s'évanouit

Au **pied** du panneau, débordant de 2px sous lui :

```css
.cart::after {
  left: 12%; right: 12%; bottom: -2px;
  height: 3px; border-radius: 0 0 4px 4px;
  background: linear-gradient(90deg,
    transparent, rgba(155,116,242,.55) 20%,
    rgba(155,116,242,.85) 50%, rgba(155,116,242,.55) 80%, transparent);
}
```

Retrait de 12% de chaque côté — pas un pourcentage libre : sous cette valeur le
rail touche les angles et redevient une bordure.

## 7. Le puits d'identité

```css
.idzone { background: linear-gradient(180deg, rgba(0,0,0,.18), rgba(0,0,0,.30)); }
.hex {
  background: #e2b84e;
  clip-path: polygon(50% 0, 100% 25%, 100% 75%, 50% 100%, 0 75%, 0 25%);
  font: 700 9.5px ui-monospace; letter-spacing: -.19px;   /* NÉGATIF */
  color: rgba(15,12,8,.8);
  box-shadow: 0 1px 2px rgba(0,0,0,.4);
}
```

L'interlettrage négatif sur l'hexagone est délibéré : un nombre à trois
chiffres doit tenir dans la largeur utile de la forme, qui se resserre en haut
et en bas.

## 8. Typographie — deux registres, mesurés

| rôle | valeur |
|---|---|
| corps / titres | `"Space Grotesk"`, 13px/19.5px |
| étiquette de commande | `600 10.5px` mono, `letter-spacing: 1.26px` (.12em) |
| barre d'état | `600 10px` mono, `letter-spacing: 1.4px` (.14em) |
| hexagone | `700 9.5px` mono, `letter-spacing: -.19px` |
| sceau | `11px`, `letter-spacing: 1.98px` (.18em) |

Le monospace ne sert **jamais** au texte courant. La vitrine NDEX l'y employait
partout, ce qui écrasait la hiérarchie : tout avait la même voix.

## Ce que le relevé invalide dans la v2

1. **Les filets or en dégradé évanescent** sur les panneaux : l'or est plein et
   de 2px. Le seul motif qui s'évanouit est le rail violet, au pied.
2. **Les modules en relief à bordure claire** : tout ce qui vit dans une coque
   est creusé. La bordure claire est l'erreur qui fait « page web ».
3. **Un rayon unique par famille** : les rayons sont asymétriques *et*
   positionnels, et les trois coques se répondent haut/bas.
4. **Les ombres portées noires** : elles sont teintées de la famille.
